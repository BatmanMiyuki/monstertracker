MONSTERTRACKER — SUPPORT
CONNEXION ADMIN

Espace réservé à l'administrateur. Connecte-toi avec ton compte admin MonsterTracker.

ACCÈS REFUSÉ

Ton compte n'est pas administrateur. Cet espace est réservé au support de l'application.

CRÉER TON CODE

Choisis un code à 6 chiffres pour protéger cet espace. Tu devras le rentrer à chaque ouverture. Il est enregistré de façon sécurisée (empreinte SHA-256) et ne peut pas être relu.

CODE D'ACCÈS

Entre ton code à 6 chiffres pour ouvrir l'espace support.

ESPACE SUPPORT

Retrouve le compte d'un utilisateur par son code (lettres + chiffres) pour l'aider à récupérer son accès. L'adresse email du compte s'affiche sur sa fiche.

🔒 Les mots de passe sont chiffrés par Firebase : personne ne peut les lire, pas même toi. La récupération se fait par email de réinitialisation officiel.
FICHE UTILISATEUR
-
-
🔒 Illisible et non stocké. Firebase ne conserve qu'une empreinte cryptée (hash) du mot de passe : il est impossible de le retrouver, c'est une protection de sécurité obligatoire.
Pour rendre l'accès à l'utilisateur : envoie-lui l'email officiel de réinitialisation ci-dessous. Il choisira lui-même son nouveau mot de passe et pourra te le communiquer.
